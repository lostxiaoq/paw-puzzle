# 魔镜关卡图案草图（任务卡 012-7 / 任务卡 013-3）

重画前先在纸上打草稿，自评标准只有一条：**6 岁孩子看一眼 + 听到名字，能不能认出来？**
认不出就换主题。`·` = 空，数字 = 第几种颜色。

## 任务卡 013-3 又换了三关（4×4 画不出细节，改简单有力的图形）

### 第 1 关「蝴蝶」→「小房子」（4×4 · 1 色 · 竖线镜子）

```
012 版：       013 版：
·11·   蝴蝶    ·11·   ← 三角屋顶
1111          1111   ← 方方屋身
1111          1111
·11·          1··1   ← 两扇小窗（镂空）
```

- 012 版自评「能认出」，但实测 4×4 里翅膀和触角挤成一团，孩子说是「饼干」。
- 013 版：屋顶 + 屋身 + 两扇窗，三个特征都是孩子画房子时的固定动作。
- 自评：能认出 ✔（红色屋顶配小窗，一听「小房子」就懂）。

### 第 3 关「小狗脸」→「小树」（4×4 · 1 色 · 竖线镜子）

```
012 版：       013 版：
1··1   狗脸    ·11·   ← 树冠尖
1111          1111   ← 树冠最宽
1111          ·11·   ← 树冠收窄
1111          ·11·   ← 树干
```

- 012 版就是一坨带耳朵的方块，孩子认不出（审查结论）。
- 013 版：上尖、中宽、下细，三层轮廓是圣诞树/松树的经典画法，绿色一涂更像。
- 自评：能认出 ✔（听到「小树」+ 绿色 + 三层轮廓）。

### 第 9 关「大骨头」横放 → 竖放（8×8 · 3 色 · 竖线镜子）

012 版是横放的骨头，两头鼓包 + 骨杆挤在 8 行里，孩子看不出是骨头。
013 版按任务卡草图**竖着放**：上下各两个圆头（棕色描边），中间是骨棒，
骨棒正中一颗粉色小爱心。

```
·220022·     ← 鼓包（棕描边）
·211112·     ← 鼓包（棕描边 + 米白骨头）
···11···     ← 骨棒（米白）
···33···     ← 粉色小爱心
···33···
···11···
·111111·     ← 底部鼓包（米白）
·11··11·
```

- 竖放后上下各有一对圆头，骨棒又长又直，「骨头竖着插在碗里」的形状。
- 自评：能认出 ✔（米白骨头色 + 双圆头 + 长骨棒，配合语音）。

- 自评：能认出 ✔（中间圆圆的糖 + 两边扭起来的糖纸，过年吃的那种）。

- 自评：勉强能认 ✔（左右两片三角翅膀 + 中间粉色结；配合语音「蝴蝶结」可以认出。
