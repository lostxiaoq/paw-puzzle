# 魔镜关卡图案草图（任务卡 012-7）

重画前先在纸上打草稿，自评标准只有一条：**6 岁孩子看一眼 + 听到名字，能不能认出来？**
认不出就换主题。`·` = 空，数字 = 第几种颜色。

## 第 1 关「蝴蝶」（4×4 · 1 色 · 竖线镜子）——重画

```
旧：           新：
1··1           ·11·   ← 两根触角并在一起，从头顶伸出来
1··1           1111   ← 展开的上下翅
1111           1111
·11·           ·11·   ← 身体收成小尾巴
```

- 旧版：两片翅膀中间空一格、和身体断开，孩子看到的是「两根柱子」。
- 新版：触角在正中间朝上翘，翅膀连成一片，下面收尖。
- 自评：能认出 ✔（翅膀 + 触角 + 收尾，轮廓像蝴蝶；语音也会说「蝴蝶」）。

## 第 3 关「小狗脸」（4×4 · 1 色 · 竖线镜子）——重画

```
旧：           新：
1··1           1··1   ← 两只尖耳朵立在头顶两角
1111           1111   ← 脑袋
1111           1111   ← 脸
·11·           1111   ← 方方的下巴（和蝴蝶的尖尾巴不一样）
```

- 旧版：就是一坨方块，耳朵和脸糊在一起。
- 新版：耳朵独立在两个上角，脑袋方方正正。
- 自评：能认出 ✔（两只立起的耳朵是狗的标志；听到「小狗脸」就明白了）。

## 第 4 关「小花」（6×6 · 2 色 · 竖线镜子）——重画

```
旧：           新：
·1111·         ··11··     ← 上花瓣
112211         ··11··
112211         112211     ← 左右花瓣 + 红花心
112211         112211
112211         ··11··
·1111·         ··11··
```

- 旧版：一个圆角方块中间一个红点，孩子说是「被子」。
- 新版：十字形的 4 片花瓣包着红花心，花瓣之间有空隙。
- 自评：能认出 ✔（花瓣 + 花心，像 photo 里的小花；黄瓣红心颜色也对）。

## 第 7 关「蘑菇」→ 换成「糖果」（6×6 · 2 色 · 横线镜子）

蘑菇横着放很别扭。换成**本来就上下对称**的糖果（两头扭着糖纸）：

```
1····1    ← 糖纸翘起来的角
11··11    ← 糖纸
·1221·    ← 糖纸边 + 粉色糖体
·1221·
11··11
1····1
```

- 自评：能认出 ✔（中间圆圆的糖 + 两边扭起来的糖纸，过年吃的那种）。

## 第 8 关「飞机」→ 换成「沙漏」（8×8 · 3 色 · 横线镜子）

「朝天看的飞机」同样是硬凑的。换成沙漏（上下完全对称）：

```
33333333    ← 上下木框（深蓝）
12222221    ← 侧框（蓝）+ 金沙
00222200
00022000    ← 细腰，沙正在往下漏
00022000
00222200
12222221
33333333
```

- 自评：能认出 ✔（两个三角肚子 + 细腰 + 上下框，沙漏的标志就是细腰）。

## 第 9 关「交叉骨头」→ 换成「大骨头」（8×8 · 3 色 · 竖线镜子）

两根骨头交叉 + 爱心，信息太多孩子看不懂。换成**一根**横放的大骨头：

```
11000011    ← 两头的圆鼓包（黄）
11000011
11222211    ← 骨干（浅棕）
11233211    ← 中间一颗粉色小爱心
11233211
11222211
11000011
11000011
```

- 自评：能认出 ✔（一根骨头：两头双鼓包 + 长杆，狗狗最爱，一听名字就懂）。

## 第 11 关「火箭」→ 换成「蝴蝶结」（8×8 · 3 色 · 横线镜子）

火箭横着飞也是硬凑的。换成蝴蝶结（左右两个大翅膀 + 中间结心，天然上下对称）：

```
11000011    ← 左右翅膀的上角
11100111
11111111    ← 结所在的最宽处
01122110    ← 往中间收，粉色结心
01122110
11111111
11100111
11000011
```

- 自评：勉强能认 ✔（左右两片三角翅膀 + 中间粉色结；配合语音「蝴蝶结」可以认出。
  如果实测孩子还是认不出，退路是换成「横放的骨头」——但第 9 关已经用了骨头，
  所以先试蝴蝶结）。
